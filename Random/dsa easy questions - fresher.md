

For a fresher, you want questions that assess problem-solving ability, understanding of data structures, and coding fundamentals, rather than advanced algorithms.

Here are some of the best DSA questions:

1. Two Sum ⭐⭐⭐⭐⭐ (Most recommended)

Given an array of integers and a target value, return the indices of the two numbers whose sum equals the target.

Example:

Input: nums = [2, 7, 11, 15], target = 9
Output: [0, 1]


Tests:

Arrays
HashMap
Time complexity optimization
2. Reverse a String

Reverse a string without using built-in reverse functions.

Example:

Input: "hello"
Output: "olleh"


Tests:

Two pointers
String manipulation
1. Find the Second Largest Element

Find the second largest element in an array without sorting it.

Example:

Input: [10, 5, 20, 8]
Output: 10


Follow-up: Can you solve it in one pass?

Tests:

Arrays
Optimization
2. Remove Duplicates

Remove duplicate elements from an array.

Example:

Input: [1,2,2,3,4,4]
Output: [1,2,3,4]


Tests:

Sets
Arrays
3. First Non-Repeating Character

Find the first non-repeating character in a string.

Example:

Input: "aabbcdde"
Output: "c"


Tests:

HashMap
Strings
4. Check Balanced Parentheses

Given a string containing (), {}, and [], determine whether the brackets are balanced.

Example:

Input: "{[()]}"
Output: True


Tests:

Stack
Logic
5. Binary Search

Explain and implement binary search.

Follow-up:

Why must the array be sorted?
Time complexity?

Tests:

Searching
Recursion/Iteration
6. Detect a Cycle in a Linked List (Theory)

How would you determine whether a linked list contains a cycle?

You don't necessarily need them to code it, but they should know about:

Fast and slow pointers (Floyd's algorithm)
If you only ask one question

I'd recommend Two Sum.

Why?

Starts with a simple brute-force solution.
Allows discussion of optimization using a HashMap.
Lets you assess:
Problem-solving approach
Data structure knowledge
Time and space complexity

A strong candidate will usually progress from:

Brute force (O(n²))
Explain why it's inefficient
Optimize to O(n) using a HashMap

That progression tells you more than whether they already know the "correct" solution.
